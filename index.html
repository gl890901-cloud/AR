🎨 AR Model Manager

Gestiona modelos 3D y genera códigos QR válidos para visualización en Realidad Aumentada

📦 Configuración del Modelo

Soporta: .glb (recomendado) o .gltf.
Ejemplo: https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/RobotExpressive.glb
Ingresa una URL de GitHub y presiona "Previsualizar Modelo"

📱 Código QR para Realidad Aumentada

📌 Instrucciones:
1. Escanea este código con tu teléfono celular.
2. Se abrirá el visor web en tu navegador móvil.
3. Haz clic en "📷 Activar Realidad Aumentada" para proyectar el modelo 3D usando la cámara trasera sobre cualquier plano.
